# 고등학생용 학습동영상 플랫폼

## 실행 방법
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 구조
- `app.py` : 로그인/회원가입/비밀번호 찾기, 홈 화면
- `db.py` : SQLite 데이터베이스 스키마 및 함수 모음
- `utils.py` : 유튜브 링크 처리 유틸
- `ai_quiz.py` : Claude API로 형성평가 문항 자동 생성
- `youtube_tracker.py` + `components/youtube_tracker/index.html` : 유튜브 IFrame API로 실시간 시청 진도 자동 추적
- `pages/1_영상목록.py` : 카테고리별 영상 목록, 진도 표시
- `pages/2_영상시청.py` : 영상 시청 + 진도 저장 + 형성평가 + 댓글
- `pages/3_영상업로드.py` : 학생/교사 공용 업로드 (학생은 승인 대기) + AI 형성평가 생성
- `pages/4_승인대기열.py` : 교사 전용, 학생 업로드 승인/반려
- `pages/5_내진도.py` : 시청 완료 수, 퀴즈 평균, 단원별 진도율

## 계정 관련
- 가입 시 비밀번호 확인, 학년/반, 번호(학생만), 비밀번호 찾기용 힌트 질문/답변을 입력
- 로그인 화면에서 "자동 로그인" 체크 시 브라우저에 로그인이 유지됨 (URL에 토큰이 포함되므로 공용 컴퓨터에서는 체크하지 않는 걸 권장)
- 비밀번호를 잊었다면 "비밀번호 찾기" 탭에서 아이디 → 힌트 질문 확인 → 힌트 답변 입력 → 새 비밀번호 설정

## AI 형성평가 자동 생성 (선택 기능)
영상 업로드 화면에서 "AI로 형성평가 자동 생성" 버튼을 쓰려면 Anthropic API 키가 필요합니다.

1. https://console.anthropic.com 에서 API 키 발급 (사용량만큼 과금)
2. Streamlit Cloud 앱 관리 화면 → Settings → Secrets 에 아래처럼 입력
   ```
   ANTHROPIC_API_KEY = "sk-ant-..."
   ```
3. 저장하면 앱이 자동 재시작되고, 업로드 화면에 AI 생성 버튼이 나타남
4. 수식은 `$x^2+1$` 처럼 `$...$` 로 감싸면 화면에 예쁘게 렌더링됨 (Streamlit이 KaTeX를 지원)

API 키를 등록하지 않으면 AI 버튼이 보이지 않을 뿐, 기존 수동 입력 기능은 그대로 사용 가능합니다.

## 시청 진도 자동 추적
- 영상 시청 화면에서 유튜브 플레이어를 직접 재생하면, 재생 위치를 감지해서 진도(%)가 자동으로 저장됩니다.
- 브라우저 확장프로그램(광고차단 등)이나 자동재생 제한으로 감지가 안 될 수 있어, "자동으로 안 올라가면 여기서 직접 수정하세요"라는 수동 보정 입력을 함께 뒀습니다.
- `components/youtube_tracker/index.html` 파일도 반드시 GitHub에 그대로(폴더 구조 유지) 올려야 동작합니다. `pages`와 마찬가지로 `components/youtube_tracker/index.html` 경로 그대로 업로드해주세요.

## 데이터
- 영상은 서버에 저장하지 않고 유튜브 링크만 저장 (임베드 재생)
- `app.db` (SQLite) 파일이 실행 위치에 자동 생성됨
- **주의**: Streamlit Community Cloud는 앱을 재부팅(Reboot)하거나 재배포하면 컨테이너 파일시스템이 초기화되어 `app.db`도 함께 사라질 수 있습니다. 회원 데이터를 계속 유지하려면 나중에 Supabase 등 외부 DB로 옮기는 걸 권장합니다.
- 최초 가입 시 역할(학생/교사)을 선택

## 배포
- GitHub 저장소에 올린 뒤 Streamlit Community Cloud로 무료 배포 가능
- 기존 myproject 앱과는 별개의 새 저장소로 관리 추천
- `pages` 폴더 안의 파일은 반드시 `pages/파일명.py` 경로로 올라가야 사이드바 메뉴로 인식됨 (최상위에 올리면 인식 안 됨)

## 향후 개선 아이디어
- 비밀번호 해시는 현재 단순 SHA-256 — 실제 운영 시 bcrypt 등으로 교체 권장
- 댓글 삭제/신고, 대댓글 기능
- 교사용 전체 학생 진도 대시보드
- 회원 데이터 영구 보존을 위한 외부 DB 연동
